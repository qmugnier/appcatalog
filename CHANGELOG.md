# Changelog

All notable changes to the Application Catalog project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-20

### Added
- Initial release of Application Catalog
- Application directory with search and filtering capabilities
- Stakeholder management system
- Application relationship tracking (functional and technical)
- Admin panel for managing applications and stakeholders
- Role-based access control (Admin/User)
- Dark mode support
- Responsive design for desktop, tablet, and mobile
- Docker support with Dockerfile configuration
- Kubernetes deployment with Helm charts
- Database migrations for schema setup
- ESLint configuration for code quality
- Tailwind CSS styling
- Supabase integration for authentication and data storage
- Component-based architecture
- Context API for state management
- Login and authentication modals
- Advanced search utilities
- Settings modal for user preferences
- Application grid and list views with pagination

### Features
- Browse all applications in the organization
- Search applications by name, code, or description
- Filter applications by functional domain and status
- View detailed application information
- Manage application stakeholders
- Track application relationships
- Admin controls for CRUD operations
- Dark/light theme toggle
- User authentication via Supabase

### Technical Details
- Built with React 18 and TypeScript
- Vite for fast build and development
- Tailwind CSS for responsive design
- Supabase for backend and authentication
- Lucide Icons for UI icons
- React Context for state management
